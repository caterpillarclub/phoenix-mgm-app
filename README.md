# Phoenix MGM Job Invoice App

## Deploy on Vercel
1. Upload the contents of this folder to your GitHub repository.
2. In Vercel, import the GitHub repository.
3. Settings:
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
4. Deploy.

## Included
- Login demo
- GPS start/stop with Google Maps embed
- Workers multiplier
- Expenses
- Deposit and payment history
- Invoice status
- Customer signatures
- Photos before/during/after
- Terms & Conditions acceptance
- Final confirmation and lock
- Legal PDF download
- Email and WhatsApp message shortcuts

## Note
This is a front-end prototype. For production use, add secure authentication, cloud database, file storage and audit logs.
